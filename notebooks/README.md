# Notebooks

This directory contains Jupyter notebooks completed as part of the CariSurg AI Healthcare Training Programme.

The notebooks implement medical data analysis and AI-assisted triage solutions are found here.

## What is a Notebook?

A Jupyter notebook is an interactive file that combines code, visualisations, and explanatory text in a single document. It has the `.ipynb` extension.

## How to run

These notebooks can be executed using:
- Jupyter Notebook (local environment)
- JupyterLab
- Google Colab (web-based)
